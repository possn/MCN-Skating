# MCN Skating — Michele Costa Nunes

**Atelier de fatos de patinagem artística** · Feito em Portugal

Site institucional do atelier MCN Skating, criado para apresentar o trabalho de Michele Costa Nunes na área da criação de fatos de competição e espectáculo de patinagem artística.

## Funcionamento

O ficheiro `index.html` é completamente auto-contido — todas as imagens estão embutidas como base64 data URIs. Basta abrir o ficheiro num browser para ver o site completo, sem necessidade de servidor.

## Tecnologia

- HTML5 semântico
- CSS puro (sem frameworks)
- Vanilla JavaScript (mínimo)
- Google Fonts: Cormorant Garamond + DM Sans
- Zero dependências externas (exceto fonte via CDN)
